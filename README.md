# Painel de Indicadores Educacionais

Primeira versão funcional do dashboard SAEB/IDEB.

## Estrutura
- `app.py`: aplicação Streamlit
- `data/base_municipios.csv`
- `data/base_escolas.csv`
- `data/investimento_inep.csv`
- `requirements.txt`

## Executar
Na pasta do projeto:

    streamlit run app.py

## Observação
Esta versão usa os CSVs completos (2005–2025) e recupera os principais modelos de comparação do notebook inicial.
